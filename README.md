# Verilog Vending Machine

A **Vending Machine Controller** designed using **Verilog HDL** and implemented using a **Finite State Machine (FSM)**.

## 📌 Overview

This project demonstrates the design of a simple vending machine controller that processes user inputs, tracks the required amount, and generates an output when the required conditions are satisfied.

The controller is implemented using FSM-based sequential logic.

## ⚙️ Features

* FSM-based design
* State transition logic
* Input processing
* Product dispensing control
* Reset functionality
* Simulation waveform verification

## 📂 Project Contents

The project contains:

* Verilog source code
* Testbench
* State diagram
* Simulation waveform
* Output

## 🧠 Design Concepts

The project demonstrates:

* Finite State Machines
* Present-state and next-state logic
* Sequential circuits
* Combinational control logic
* Clock and reset handling

## 🛠️ Tools Used

* Verilog HDL
* HDL Simulation Tool
* EDA Playground/Vivado
## 🎯 Learning Outcomes

* Understanding FSM architecture
* Designing state-based controllers
* Implementing state transitions in Verilog
* Creating testbenches
* Analyzing simulation waveforms
